# Course-inspired practice

Compared against `origin/main` at `ed9c31b`: the engine allows short selling by default, uses absolute return in its trainer score, has no benchmark, and advances the simulated year continuously. The main session setup permits different durations and starts from HKD 10M. These gaps remain on main. The review's course descriptions are user-provided; event-day rules have not been independently verified.

New course-inspired sessions snapshot USD 20M and disable shorting. Four 15-minute trading quarters are separated by three 15-minute rebalancing windows (105 minutes after the briefing); the simulation tick, prices, news and financing freeze while trading stays open. Shortened mode uses 5 minutes for each trading quarter and each rebalancing window. Existing sessions and Learn retain their stored rules; the separate legacy preset uses HKD 20M, the existing trading rules and no rebalancing windows. Team sessions use the same wall-clock schedule from their shared start time.

The benchmark display is **not** the course benchmark. It is a buy-and-hold proxy: 12.5% each in 2800 (HSI ETF), SPX, NKY and SX5E; 15% each in UST20 and HKGB; and 10% each in gold and Brent. These are the existing trainer assets, not the course's full 12-market universe. The fixed initial allocations drift with prices; returns use the same simulated paths as the portfolio, without currency conversion or benchmark transaction costs. The proxy is unavailable if any required path is missing. Excess return is portfolio return minus proxy return. For new sessions with the versioned course scoring flag, the return component of the shared portfolio score uses excess return; the existing trainer score weights, return bounds and other components are assumptions, not official scoring. Old snapshots keep absolute-return scoring. Individual contribution scores remain absolute-return based. New course sessions require all proxy price series; the UI currently restricts them to synthetic scenarios.

USD is the course preset's account-unit label: the current engine does not convert mixed-currency asset prices into a USD base currency. Consequently this preset is not an accurate multi-currency valuation model. New course sessions disallow borrowing and reject purchases above USD 5M per asset (valued using engine price units). Prices may subsequently drift above the cap; sales that reduce exposure remain allowed. The 90% investment minimum is an informational warning, not enforced. The loss cap and benchmark deviation band are not enforced: per-trade loss accounting and the benchmark-band units are unverified. Client mandates and the simulated instrument universe remain trainer assumptions, not verified Wealthathon rules. Rebalancing compares current class exposures with initial proxy class targets; it does not save an independent strategy or calculate drifted benchmark weights.
