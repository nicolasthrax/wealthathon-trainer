# Course-inspired practice

Compared against `origin/main` at `ed9c31b`: the engine allows short selling by default, uses absolute return in its trainer score, has no benchmark, and advances the simulated year continuously. The main session setup permits different durations and starts from HKD 10M. These gaps remain on main. The review's course descriptions are user-provided; event-day rules have not been independently verified.

New course-inspired sessions snapshot USD 20M and disable shorting. Four 15-minute trading quarters are separated by three 15-minute rebalancing windows (105 minutes after the briefing); the simulation tick, prices, news and financing freeze while trading stays open. Shortened mode uses 5 minutes for each trading quarter and each rebalancing window. Existing sessions and Learn retain their stored rules; the separate legacy preset uses HKD 20M, the existing trading rules and no rebalancing windows. Team sessions use the same wall-clock schedule from their shared start time.

The benchmark display is **not** the course benchmark. It is a buy-and-hold proxy: 12.5% each in 2800 (HSI ETF), SPX, NKY and SX5E; 15% each in UST20 and HKGB; and 10% each in gold and Brent. These are the existing trainer assets, not the course's full 12-market universe. The fixed initial allocations drift with prices; returns use the same simulated paths as the portfolio, without currency conversion or benchmark transaction costs. The proxy is unavailable if any required path is missing. Excess return is portfolio return minus proxy return. The displayed score remains the existing assumed, absolute-return trainer score, not official scoring.

USD is the course preset's account-unit label: the current engine does not convert mixed-currency asset prices into a USD base currency. Consequently this preset is not an accurate multi-currency valuation model. Existing client-specific mandates, leverage, limits and the simulated instrument universe are also trainer assumptions, not verified Wealthathon rules. The course-reported 90% investment, per-asset cap, loss cap, benchmark deviation band, and any event-day quarter transition rules are not implemented as official constraints. Rebalancing compares current class exposures with initial proxy class targets; it does not save an independent strategy or calculate drifted benchmark weights.
